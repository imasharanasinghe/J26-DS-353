# Component 1: Pedagogy-Aware Knowledge Graph Construction

This component prepares course captions, extracts data-structure and algorithm concepts, and identifies candidate pedagogy relations for verification.

## Contents

- `data/raw/Captions_algorithms_Princeton.json` — course caption source file.
- `data/processed/chunks.csv` — overlapping text chunks generated by stage 1.
- `src/stage1_prepare.py` — cleans captions and creates text chunks.
- `src/stage2_concepts.py` — finds candidate concepts in the chunks.
- `src/stage3_relations.py` — extracts candidate prerequisite, Bloom-level, and misconception relations.
- `test_connection.py` — checks Neo4j connectivity using local environment settings.
- `outputs/` — current intermediate CSV results from concept and relation extraction.

The output CSVs are reproducible intermediate snapshots, not verified final knowledge-graph edges. The verifier, graph-storage, and evaluation stages are not implemented in this snapshot.

## Setup

Run commands from this directory:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m spacy download en_core_web_sm
Copy-Item .env.example .env
```

Edit `.env` locally with your own Neo4j settings and API key. Never commit `.env` or share its values.

## Run the pipeline

```powershell
python src\stage1_prepare.py
python src\stage2_concepts.py
python src\stage3_relations.py
```

Stage 1 writes `data/processed/chunks.csv`; stages 2 and 3 write CSVs under `outputs/`. Stage 2 requires the `en_core_web_sm` spaCy model. The scripts use paths relative to this component directory.

The default extraction sample is 100 chunks. Relation candidates are heuristic and should be reviewed by the later verifier before being treated as knowledge-graph facts.
